# Hangman Word Guessing Game

## Description
A simple console-based game developed using Python. The player guesses a randomly selected word within 6 incorrect attempts.

## Technologies Used
- Python 3
- VS Code / PyCharm
- Random module

## Features
- Random word selection
- ASCII gallows art
- Tracks guessed letters
- Prevents duplicate penalties
- Victory and defeat messages

## How to Run
1. Install Python 3.
2. Create `hangman.py` and paste the code.
3. (Optional) Download the word list as `words.txt`.
4. Open the terminal and run:

```bash
python hangman.py
```

## Sample Output

**Winning:**
```text
CONGRATULATIONS! YOU WIN!
You guessed the word: python
```

**Losing:**
```text
GAME OVER! YOU LOST.
The secret word was: python
```
